# 工数ログ

顧問先別に工数・メモ・決算の進捗を記録する縦型タイムラインのPWA。外部依存なし・LocalStorage保存。

公開URL: https://forestmtk.github.io/time-tracker/

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | ロジックはすべてここ。ビルド不要 |
| `manifest.json` | PWAの定義。`id` は `"/time-tracker/"` 固定（**変更するとPWAが別アプリ扱いになる**） |
| `icon-192.png` / `icon-512.png` / `icon-maskable-512.png` | アイコン。名前は `manifest.json` の `src` と一致させる |

サービスワーカーは置いていない。「開けば最新版」を優先し、オフライン起動は捨てている。
版数は `index.html` の `const APP_VER`。設定画面の見出し右に表示される。

## 主な機能

- タイムラインで工数を記録（開始/停止、後からの手入力・修正・複製）
- 締め忘れ検知（前日以前の計測が止まっていなければ起動時に促す）
- 集計（日/月の切替。顧問先別・業務別の合計、月は稼働日数とコピー）
- **決算の進捗ボード**（8工程。着手は業務名から自動、完了は手で押す）
- **メモ記法**：`- [ ]` やること／`#預り`→`#返却`／`#論点`→`#判断`／`#提出`→`#戻り`
- 日報の書き出し（Markdown / テキスト。コピー、またはObsidianフォルダへ直接保存）
- 申告チェックリストの取り込みブロック貼り付け

## データ

- 保存先: ブラウザのLocalStorage（キー `timeTracker.v1`）。**端末・ブラウザ単位。サーバには送信しない**
- バックアップ: 設定からJSONを書き出し／読み込み（`time_tracker_backup_YYYY-MM-DD.json`）
- 設定（顧問先・決算月・業務）だけを、記録を壊さずに別端末へ配ることもできる
- `forestmtk.github.io` はGitHub Pagesの共有オリジン。LocalStorageの5MiBは他のPagesと共有

## Obsidian 直接保存 / PWA

- 初回に書き出しシートで保存先フォルダを一度選ぶ
- **Chromeを使うこと。** 3択の「サイトアクセス時は常に許可」を選べば権限が永続する。
  **Edgeでは永続しない**（インストール済みPWAでも毎回聞かれる。2026-08の実機で確認）
- インストール: アドレスバーのアイコン、または ⋮ → キャスト、保存、共有 → ページをアプリとしてインストール
- ログイン時の自動起動: `chrome://apps` → 右クリック → 「パソコンへのログイン時にアプリを起動する」
- 日報は `YYYY-MM-DD.md` に `<!-- time-tracker -->`〜`<!-- /time-tracker -->` のブロックとして書き込む。
  手書き部分は保持され、再保存でブロックだけ差し替わる
- iPhone / Safari はファイル書き込み非対応のため、コピーして貼り付け運用

## 更新のしかた

`index.html` を差し替えるだけ。URL・LocalStorageのデータは据え置き。
**`APP_VER` を更新すること**（日付＋a,b,c…）。
